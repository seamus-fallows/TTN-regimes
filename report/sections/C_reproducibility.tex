\section{Reproducibility}\label{app:reproducibility}

Every figure, and every table and number computed from runs, is regenerated by a script in the
repository from saved outputs. The analysis scripts of each experiment reduce its raw runs to small
tables in \path{experiments/<name>/results/}, which are committed; the report figures, tables and
derived numbers are drawn from these tables (\path{plot_report.py}, \path{report_numbers.py} or
\path{make_figures.py} of the experiment), and only the figures that plot trajectories also read raw
runs (\cref{tab:repro-figures}). The sweeps that produced the raw runs are configured by YAML files
(\cref{app:experiments}), seeded and resumable, and each experiment's README lists every step in
order. All figure and table commands, and the analysis steps that feed them, were rerun on the saved
outputs and compared with the committed files; \path{notes/reviews/reproducibility_check.md} records
the result, including the few entries that do not regenerate exactly.

\subsection{Software and data}\label{app:repro-software}
The code is a uv project: Python 3.13, dependencies in \path{pyproject.toml} with exact versions in
\path{uv.lock} (PyTorch 2.14.1, NumPy 2.5.3, SciPy 1.18.1, pandas 3.0.6, Matplotlib 3.11.2);
\texttt{uv sync} installs it and \texttt{uv run pytest} runs the tests of the shared library
\path{ttn/} (trees, networks, teachers, exact losses, integrators, diagnostics, plotting). All
numerics are in double precision. The check above used the library at commit \texttt{3a642ef} (code
hash \texttt{6d786ce7\ldots}, the SHA-256 of \path{ttn/*.py} computed by \texttt{ttn.runner.code\_hash});
runs made with \texttt{ttn.runner} store the commit and this hash in their metadata.
Each experiment has a folder \path{experiments/<name>/} with a README (question, setup, commands in
order, variants, results), \path{configs/}, its code and \path{results/}. Raw outputs (per-run
records and trajectories) are not in git: the sweeps wrote them to \path{/root/outputs/<name>/} on
rented machines, from where they were copied to \path{data/<name>/} (gitignored) and verified byte for
byte before the machines were deleted; local reruns are in \path{data/<name>_local/} and the
reviewers' reruns in \path{data/review_<name>/}. Scripts written by the reviewers and verifiers, the
source of some numbers in \path{notes/reviews/}, are kept for provenance in
\path{notes/reviews/scripts/}.

\subsection{Building the report}\label{app:repro-build}
The report is built by \path{report/build.sh} (pdflatex, BibTeX, then pdflatex until the
cross-references are stable), after \path{report/collect_figures.sh} has copied the figures listed
in \path{report/figures.txt} from \path{experiments/*/results/} into \path{report/figures/}.
\path{report/README.md} describes both scripts.
