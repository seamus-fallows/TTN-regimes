\paragraph{How to read this.} Each result carries two labels.
\emph{Novelty}: \NEW{} means we found no earlier statement of it; \TTN{} means the mechanism was known in
other models and we worked out what it does in tree networks; \KNOWN{} means it was already known.
\emph{Evidence}: \ev{proven} (a mathematical proof), \ev{derived} (a calculation that relies on stated
approximations), \ev{empirical} (measured in simulations), \ev{conjecture} (a hypothesis we have not tested).
Every simulation claim was re-checked by an independent agent, except one, which is marked.

\section{The setting in plain terms}

\paragraph{The model.} The input is $N$ vectors $x_0,\dots,x_{N-1}\in\mathbb R^d$, for example $N$ pixels.
The model's output is a weighted sum over all products of one entry from each vector:
\begin{equation}
f(x)=\sum_{i_0,\dots,i_{N-1}} W_{i_0 i_1\cdots i_{N-1}}\; x_0[i_0]\,x_1[i_1]\cdots x_{N-1}[i_{N-1}] .
\end{equation}
The weight array $W$ has $d^N$ entries, which is too many to store, so a \textbf{tree tensor network}
(TTN) builds $W$ from $K$ small arrays called \textbf{cores}. The cores sit at the nodes of a tree. Each
input position (a \textbf{site}) attaches to one core, and neighbouring cores are joined by a shared index
of size $\chi$, the \textbf{bond dimension}. Summing over the shared indices gives $W$. A larger $\chi$ lets the
network represent more tensors. We compare three tree shapes (Fig.~\ref{fig:route}):
\begin{itemize}
\item \textbf{MPS} (a chain): one core per site, $K=N$.
\item \textbf{Binary tree}: sites attach in pairs to the bottom cores, with $K=N-1$.
\item \textbf{Hierarchical Tucker (HT)}: every site has its own leaf core, with a binary tree above,
$K=2N-1$. The upper cores carry no sites.
\end{itemize}

\paragraph{The task.} A \emph{teacher} tensor $W^*$ is a sum of $R$ \textbf{components} with weights
$s_1>s_2>\dots$:
\begin{equation}
W^*=\sum_{r=1}^R s_r\, u^{(r)}_0\otimes u^{(r)}_1\otimes\dots\otimes u^{(r)}_{N-1}.
\end{equation}
In our main examples each $u^{(r)}_n$ is a basis vector. A component can then be written as a string such
as $00011000$, which lists the basis vector used at each site. With whitened Gaussian inputs, the expected
squared error is, up to a constant,
\begin{equation}
L=\tfrac12\,\lVert W-W^*\rVert^2 .
\end{equation}

\paragraph{Training.} We use \textbf{gradient flow}, $\dot\theta=-\nabla L(\theta)$ (gradient descent with
very small steps), where $\theta$ collects all core entries. The cores start random with overall size
$\sigma$, the \textbf{initialization scale}. The output $f$ is a product of $K$ cores, so it starts at a
size of roughly $\sigma^K$.

\paragraph{Vocabulary for the dynamics.}
\begin{itemize}
\item \textbf{Plateau}: a long stretch in which the loss barely moves. \textbf{Saddle-to-saddle} training
means the loss falls in steps, with one plateau before each component is learned.
\item \textbf{Saddle}: a point where the gradient is zero but which is not a minimum. Plateaus happen near
saddles.
\item \textbf{Order of a saddle}: the smallest $p$ such that moving a distance $\varepsilon$ in some
direction lowers the loss by about $\varepsilon^p$. Order $p=2$ is a \textbf{strict} saddle, where some
direction curves downward. For $p\ge3$ the loss is flat to second order, so escape is much slower.
\item \textbf{Lazy regime}: the weights barely move during training, and the network behaves like a linear
model with fixed features (a ``kernel''). \textbf{Rich regime}: the features change, but without clear steps.
\end{itemize}

\paragraph{The one equation behind most results.} Suppose $m$ cores must all grow from size $\sim\sigma$ for
the loss to fall, while the other cores are already of size $O(1)$. The gradient on each small core is a
product of the other $m-1$ small cores, so their common size $a$ obeys
\begin{equation}\label{eq:grow}
\dot a\approx c\,a^{m-1},\qquad a(0)\sim\sigma
\quad\Longrightarrow\quad
T_{\rm plateau}\approx\begin{cases}O(1) & m=1,\\[2pt] \dfrac{\ln(1/\sigma)}{c} & m=2,\\[6pt]
\dfrac{\sigma^{-(m-2)}}{(m-2)\,c} & m\ge3.\end{cases}
\end{equation}
For $m\ge3$ the solution blows up at a finite time, so the size stays near $\sigma$ for a long time and then
shoots up: this is the plateau and the sudden drop. Here $c$ is proportional to the weight of the component
being learned. Equation~\eqref{eq:grow} is standard for products of weights. Our results concern
\emph{what $m$ is} in a tree network, \emph{which} cores are small, and when the simple picture fails.

\section{The results explained}

\subsection*{R1. One component at a time \hfill\TTN}
From small $\sigma$ the loss falls in steps, and each step learns one component \ev{empirical}. Before
the first step all $K$ cores are small, so $m=K$ in \eqref{eq:grow}:
\begin{equation}
T_1\approx\frac{\hat t(Z)}{s_1\,\sigma^{K-2}},
\end{equation}
where $Z$ is the random initial direction. We compute the number $\hat t(Z)$ by solving one
$\sigma$-independent equation \emph{before training starts}. It predicts the first escape time, and which
component is learned first in 1,847 of 1,848 runs \ev{derived, empirical}. The textbook estimate based
only on the initial norm underestimates $T_1$, by up to a factor of $3\cdot10^7$.
\emph{Known:} the $\sigma^{-(K-2)}$ law and the per-initialization formula hold for any model that is a
product of $K$ weight layers \citep{kumar2025early,kunin2025alternating}. \emph{New:} evaluating them for
trees and testing them run by run.

After the first component is learned, most cores are already large. To learn the next component, the
network needs to change only some of them:
\begin{itemize}
\item the cores holding the sites where the new component \emph{differs} from what is already learned;
\item every core on the tree path connecting those cores, because the new information has to pass through
them.
\end{itemize}
We call this connected set of cores the \textbf{route}, and write $k$ for its number of cores (in graph
theory it is the Steiner tree of those cores). Only the route cores start small in the new direction, so
$m=k$ in \eqref{eq:grow}:
\begin{equation}
T_{\rm next}\;\propto\;
\begin{cases}O(1)&k=1\ \text{(no plateau)},\\ \ln(1/\sigma)&k=2,\\ \sigma^{-(k-2)}&k\ge3.\end{cases}
\end{equation}
We measured the exponent $k-2$ for $k=1,\dots,5$ in about 11,600 runs on nine trees \ev{empirical}. The
logic leading to it is \ev{derived}, and the count of route cores is \ev{proven}.
Two consequences:
\begin{itemize}
\item \textbf{Locality beats weight.} As $\sigma\to0$, a \emph{smaller} component with a shorter route is learned before a
larger component with a longer one. This is the reverse of the usual ``largest first'' rule.
\item \textbf{The same task gives different laws on different trees} (Fig.~\ref{fig:route}): logarithmic on an MPS,
$\sigma^{-3}$ on a binary tree, about $\sigma^{-5}$ on HT \ev{empirical}.
\end{itemize}
\emph{Known:} \citet{rawal2026theory} give escape laws in terms of the number of small layers, in an
abstract form. \emph{New:} identifying which cores are small (the route) and how this depends on the tree.

\subsection*{R3. The saddle-order theorem \hfill\NEW\ \ev{proven}}
R2 assumes that the saddle after a learned component has order $p=k$. We proved when this is exactly true
\ev{proven, checked twice independently}:
\begin{itemize}
\item \textbf{When it holds.} Let $s_j$ be the weight of the learned component. We define a matrix
$\mathcal S$ that measures how strongly the components still to be learned couple through small groups
of cores. If its largest eigenvalue satisfies $\lambda_{\max}(\mathcal S)<s_j$, the order is exactly $k$.
This always holds when the teacher has two components learned largest first, and also for routes of
3 or 4 cores under a mild condition.
\item \textbf{When it fails.} If $\lambda_{\max}(\mathcal S)>s_j$, the network can take a shortcut: it
splits the route into two pieces of at most $\ell$ cores each and escapes with order $2\ell<k$. This can
happen when a larger component is still unlearned, or when several unlearned components share cores. The
first counterexample has $k=5$ and order $4$, on an MPS with 6 sites.
\end{itemize}
\emph{What this predicts for training:} where the shortcut exists, escape is faster than the route rule
says. A pre-registered test (about 2,800 runs) measured exponents $2.001$ (order 4, route rule $3$) and
$3.996$--$3.998$ (order 6, route rule $5$), as predicted, when the starting point is close enough to the
saddle; results were mixed further away \ev{empirical; \textbf{not} independently re-checked}.
\emph{Known:} an \emph{upper} bound on the order (no larger than the number of rank-deficient cores,
\citealp{furman2026benign}); lower bounds only for deep linear networks \citep{achour2024loss}.
\emph{New:} that the relevant number is the route size, which can be much smaller, plus the exact
condition and the shortcut.

\subsection*{R4. Tree shape decides whether saddles are strict \hfill\NEW\ \ev{derived, empirical}}
When the teacher's components are not exactly orthogonal, which is the generic case, the components
overlap, and this overlap creates new routes of only two cores, but only between \emph{neighbouring cores
that both carry sites}. An MPS has such pairs everywhere, so its saddles become strict ($p=2$) and the
plateaus become logarithmic. In binary and HT trees the internal cores carry no sites, so the saddles stay
higher-order and the plateaus stay power laws (13 teachers, $N=4$ and 8).

\subsection*{R5. Which component comes first \hfill\TTN}
Suppose two components compete, and they differ from each other at sites spread over $k$ cores.
\begin{itemize}
\item \textbf{$k\ge3$: a race.} By \eqref{eq:grow} each finishes at
$T_r\propto(\sigma z_r)^{-(k-2)}/s_r$, where $z_r$ is a random number from the initialization. The ratio
$T_1/T_2$ does not depend on $\sigma$, so the winner is random with fixed odds
\ev{proven at leading order on MPS; empirical, 67,200 runs}.
\item \textbf{$k=2$: greedy.} Now $T_r\approx\ln(1/\sigma)/s_r$, so the larger component wins with
probability $\to1$ as $\sigma\to0$ \ev{derived, empirical}.
\end{itemize}
\emph{Known:} greedy learning in deep linear networks \citep{saxe2014exact,jacot2022saddletosaddle}, and
races between spikes in tensor PCA \citep{benarous2025stochastic}. \emph{New:} the split by number of cores,
and the exact race on MPS.

\subsection*{R6. Dead routes: getting stuck for good \hfill\NEW{} (related ideas known)}
Some runs never learn a component, because a core at an \emph{end} of its route shrinks to numerical zero
(398 of 5,682 runs, all with $k\ge4$; most runs with $K=7,8$ at tight $\chi$) \ev{empirical}. Gradient flow
conserves, for every bond, the difference of the squared sizes of the two cores it joins (as in deep
linear networks). For each route end, the sign of this conserved quantity, which is fixed at
initialization, decides whether that end can grow or must die \ev{derived}. The prediction from the
initialization alone works: 93\% of runs predicted dead stall, against 1.8\% of runs predicted alive
\ev{empirical}. Initializing with balanced core sizes prevents leaf ends from dying.
\emph{Known:} stalls caused by unbalanced initialization \citep{furman2026benign}. \emph{New:} the route-end
criterion and its probabilities.

\subsection*{R7. Map of regimes \hfill\NEW}
As $\sigma$ grows, training goes from saddle-to-saddle, through a rich window, to lazy \ev{empirical}. The lazy
regime exists \emph{only if} every bond is full, meaning it has the largest rank it can possibly need:
\begin{equation}
\chi_e\;\ge\;\min\big(d^{\,n_e},\,d^{\,N-n_e}\big)\quad\text{for every bond }e,
\end{equation}
where $n_e$ is the number of sites below bond $e$. Without this, large-$\sigma$ training stalls at a loss floor
\ev{derived, empirical}. On the binary tree with 4 sites, both boundaries scale as $\chi^{-1/2}$, with
$\sigma_{\rm lazy}\approx6.5/\sqrt\chi$ \ev{derived, empirical}.
We also give a TTN version of the $\mu$P scaling, which keeps feature learning as $\chi$ grows \ev{derived}.

\subsection*{R8. Other optimizers \hfill mixed}
\begin{itemize}
\item \textbf{Gradient descent} with step $\eta$ follows the same sequence of saddles if
$\eta<\eta_c=2/(K\,s_1^{\,2-2/K})$ \ev{proven}; above $\eta_c$ it oscillates or diverges. \TTN{}
(cf.\ \citealp{macdonald2025convergence}).
\item \textbf{SGD} never shortens the first plateau on average. It lengthens later plateaus and can stall a
run \ev{empirical}. \TTN
\item \textbf{Adam} still learns one component at a time, but the first escape takes a number of steps
independent of $\sigma$, until $\sigma$ is so small that Adam's $\epsilon$ dominates \ev{derived, empirical}.
\KNOWN{} (concurrent work, \citealp{sabanayagam2026optimizer}).
\item \textbf{ALS, DMRG, Riemannian GD} (standard tensor-network optimizers) have no plateaus \ev{derived}.
\end{itemize}

\subsection*{R9. Real data: MNIST \hfill\NEW}
On a binary tree over pixels, the first route learned is a pair of neighbouring cores ($k=3$). A test
designed before the data was seen compared 27 pixel orderings. A data-only measure of how strongly
short routes couple predicts the final loss (rank correlation $-0.60$, 95\% CI $[-0.82,-0.22]$) but not
the training speed. Spatial closeness of pixels by itself is not the cause \ev{empirical}. Why the measure
works is a \ev{conjecture}.

\section{What was already known}
\KNOWN{} The binary tree with 4 sites is mathematically a 3-layer linear network, so its stepwise
learning, largest-first order and strict wrong-order saddles were known
\citep{saxe2014exact,jacot2022saddletosaddle,achour2024loss}. Also known: the balanced escape direction from
zero \citep{kumar2025early}; the two-core case, which is matrix factorization \citep{jiang2023algorithmic};
the bias of hierarchical tensor factorization toward low rank \citep{razin2022implicit}.
To our knowledge no earlier paper describes saddle-to-saddle dynamics of tree networks with three or more
cores.

\section{Main caveats}
\begin{itemize}
\item Small trees ($N\le16$, mostly $N\le8$), exact expected loss, whitened Gaussian inputs, and
mostly synthetic teachers.
\item The boundary between saddle-to-saddle and rich training for large trees is open.
\item The MNIST mechanism is a conjecture.
\item The R3 dynamics test was not independently re-checked.
\end{itemize}
The full report has all numbers, error bars, and a record of claims withdrawn after review.
