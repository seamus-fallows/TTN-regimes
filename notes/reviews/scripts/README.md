# Review and verification scripts (provenance)

Scripts written by the independent reviewers and verifiers (local agents) while checking each experiment.
Folder names: `review_<experiment>/` (review round 1), `verify_<experiment>...` (verification of fix rounds).
They are kept for provenance: some numbers in `notes/reviews/*.md`, and a few quoted in the report, come
only from these scripts. They are not maintained, may contain hard-coded paths to the reviewers' scratch
directories or to `data/review_<experiment>/` (gitignored re-run outputs), and are not part of the library.
Copied from the lead's session scratchpad on 2026-10-10 (scripts and markdown only; outputs omitted).
