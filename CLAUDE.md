# CLAUDE.md — project map

Completed research project: **training dynamics of tree tensor networks (TTNs)**. Which regimes
(saddle-to-saddle / incremental, lazy, rich, others) occur, which parameters select them, with theory
checked against experiments. Main focus: saddle-to-saddle.

The project is finished (2026-10-11). The end product is the report `report/main.pdf` (164 pages), which is
the authoritative statement of the results. Sessions here are for questions about the results and for small
follow-up investigations: work directly in this session.

The project was run as an automated multi-agent research project. That setup (lead instructions with the
interim findings digest, agent-management memories) is archived in `notes/autoresearch/`; `PLAN.md` and
`notes/briefs/` are the plan and agent briefs. They are history: do not follow them unless asked.

## Environment and conventions

- uv project (Python 3.13). Always `uv run python ...`, `uv run pytest`. Add deps with `uv add`.
- All numerics in float64 (plateaus at small init involve values ~1e-12 and below).
- Code style: simple research code, clear names, comments only for *why*. Shared code goes in `ttn/`;
  experiment-specific scripts live in the experiment folder.
- Experiments are config-driven (YAML in `experiments/<name>/configs/`) and seeded; every figure is
  regenerated by a script in the repo. **Teacher seeds and init seeds are independent streams**
  (`ttn.teachers.teacher_generator`); results computed before commit 57d5262 used shared streams and are invalid.
- Large raw outputs are NOT in git: they live in `data/<experiment>/` (gitignored). Each experiment README says
  where. saddle-dyn's raw outputs were never copied (summary CSVs are in `experiments/saddle_dyn/`).
- Status tags for claims: **proven**, **derived** (under stated assumptions), **empirical**,
  **conjecture**. The report marks new vs known results.
- Call `torch.set_num_threads(1)` in every experiment process (small linear algebra is 100-1000x slower with many threads on a loaded machine).
- Later plateaus are stiff (learned directions have O(1) Hessian eigenvalues): use `integrate_gf(..., method="lsoda")` once a component is learned.
- float64 floor: a dormant component whose escape signal falls below ~1e-15 is seeded by roundoff, not by the init; flag such runs.

## Shared library `ttn/`

| module | contents |
|---|---|
| `tree.py` | `Tree` (parent array + sites per node), `binary_tree` (K = N-1), `mps_tree`, `ht_tree`, `make_tree`; subtree sites, paths, Steiner subtrees |
| `network.py` | `TTNSpec` (`init` = fan-in Gaussian, scale sigma), `forward`, `to_dense`, `inner`, `bond_spectra` (QR sweeps, ~1e-15 relative), `conserved_quantities` (`n_copies=2` for two-copy), `antisymmetric_double` (+ mask), `two_copy_cores`, `sum_difference_cores` (cancellation-free two-copy), `aligned_init` |
| `general.py` | `inner_general`: TTNs on different trees |
| `teachers.py` | `CPTeacher` (odeco / pattern / random CP; `component_overlaps` reaches 1 at W* also under covariance), `TTNTeacher`, `ShiftedTeacher`, `teacher_generator` |
| `losses.py` | exact `population_loss`, `centred_population_loss` (use for the centred model at large sigma), `empirical_loss`, `sample_inputs`, `power_law_cov` |
| `diagnostics.py` | ranks, events (`crossing_times`, `event_widths` = final rise, `separation_ratios`), `find_plateaus`, `classify_regime`, `plateau_scaling`, tangent kernels, Hessian/Lanczos, gauge directions + projection, `saddle_type`, `saddle_scaling` (classify by lambda_min scaling with sigma), `projected_fit_loss` (lazy floor), `gauge_projected_eigs`, `plateau_hessians` |
| `theory.py` | balanced/unbalanced mode solutions, exact and asymptotic escape times, odeco aligned predictions |
| `plotting.py` | style, loss/overlap/spectra/scaling/phase-diagram plots, `fit_power_law`, `savefig` |
| `dynamics.py` | `Problem` (cancellation-free `effective` tensor for centred/two-copy), `integrate_gf` (`method="dopri5"` or `"lsoda"` for stiff later plateaus, `"radau"`), `run_gd`, `run_sgd`, `make_dataset`, `Recorder`, `Trajectory`, `log_time_grid` |
| `config.py`, `runner.py` | YAML configs (validated), `run`, `summary` (events on log + fine rows, resolution checks, regime, lazy floor, float64-floor flag), `run_sweep` (parallel, resumable, refuses mixed configs, lock file), CLI `uv run python -m ttn.runner CONFIG.yaml [--grid G.yaml] [--seeds 0-9] [--out DIR] [--workers N] [key=value ...]` |

Recorder keeps "fine rows" (log + integrator steps where theta or log L moved by 1%): use
`ttn.dynamics.merged_rows` for events. Example experiment: `experiments/00_smoke/`.

Library facts that bite: the two-copy model is not a doubled-bond TTN without a gradient mask; centred/two-copy
losses cancel catastrophically at large sigma (use the cancellation-free forms).
