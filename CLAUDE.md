# CLAUDE.md — project map

Research project: **training dynamics of tree tensor networks (TTNs)**. Which regimes
(saddle-to-saddle / incremental, lazy, rich, others) occur, which parameters select them, with theory
checked against experiments. Main focus: saddle-to-saddle. End product: LaTeX report in `report/`.

Read this file first; it is how the lead and all agents recover context. Keep it current.

## Environment and conventions

- uv project (Python 3.13). Always `uv run python ...`, `uv run pytest`. Add deps with `uv add`.
- All numerics in float64 (plateaus at small init involve values ~1e-12 and below).
- Code style: simple research code, clear names, comments only for *why*. Shared code goes in `ttn/`;
  experiment-specific scripts live in the experiment folder.
- Experiments are config-driven (YAML in `experiments/<name>/configs/`) and seeded; every figure is
  regenerated by a script in the repo. **Teacher seeds and init seeds are independent streams**
  (`ttn.teachers.teacher_generator`); results computed before commit 57d5262 used shared streams and are invalid.
- Large raw outputs are NOT in git: remote agents write them to `/root/outputs/<experiment>/`; the
  lead copies them to `data/<experiment>/` locally (gitignored). Each experiment README says where.
- Status tags for claims: **proven**, **derived** (under stated assumptions), **empirical**,
  **conjecture**. The report marks new vs known results.
- Write large files in small pieces and keep final answers short (two agents died hitting the 64k output-token limit).
- Never kill processes by name (`taskkill /IM python.exe`, `pkill python`): several agents share machines. Kill only PIDs you started.
- Call `torch.set_num_threads(1)` in every experiment process (small linear algebra is 100-1000x slower with many threads on a loaded machine).
- Later plateaus are stiff (learned directions have O(1) Hessian eigenvalues): use `integrate_gf(..., method="lsoda")` once a component is learned.
- float64 floor: a dormant component whose escape signal falls below ~1e-15 is seeded by roundoff, not by the init; flag such runs.

## Key findings so far

- Literature: no paper characterizes saddle-to-saddle dynamics of gradient flow on dense-core TTNs with K >= 3
  cores (the two-core case is a depth-2 matrix factorization, solved by Jiang, Chen & Ding 2023); Q1–Q3 is
  the top open problem; near-origin escape is a corollary of Kumar & Haupt 2025; Furman et al. 2026 treat
  exactly our model's landscape (no spurious minima for realizable targets along balanced trajectories;
  descent order bounded by the rank-deficient core size).
- Theory (theory_saddles.md v2, verified): after the first escape the next escape takes the route with the
  fewest cores k* (Steiner subtree of the cores carrying the differing sites; identity proven, saddle order = k*
  derived), not the largest component; k* = 2 strict with lambda = s_r s_q^((K-2)/K) (to 6 digits), k* >= 3
  higher-order; escape times carry a head start (1 - s_r/s_q) (k >= 3 head start new); with several residual
  components sharing a terminal core the saddle is strict iff rho(S) > s_q ("star" teachers: a larger learned
  component is forgotten and relearned); gradient flow can trap when ALL route ends are gauge-unfavourable.
  General machinery overlaps Kumar & Haupt 2025c, Rawal & DeWeese 2026, Furman 2026 (section 9 of the note).
- Experiments (interim, pending review): order: on matrix-like pairs (binary4 = depth-3 DLN) P(wrong order) ~ sigma^gamma
  with gamma = 0.42/0.25/0.10/0.04 vs (1-rho)/rho = 0.43/0.25/0.11/0.05, and the wrong order is corrected through a strict
  saddle (slope 5.39 vs 5.386 predicted); on tensor-like trees (MPS4) P(greedy) is sigma-independent (0.815/0.605/0.51).
  regime-map: lazy regime exists only when chi reaches the cut dimension; below it centred runs stall at the best fit.
  optimizers: Adam/RMSProp keep weight-ordered sequential learning but REMOVE the sigma^-(K-2) plateau scaling (first
  escape in a sigma-independent number of steps); re-gauged GD, Riemannian GD, Gram preconditioning, ALS, DMRG remove
  plateaus altogether. data-teacher: any non-orthogonality (misaligned covariance, CP overlap, correlations, generic TTN
  teachers) turns MPS later plateaus into strict log-time saddles (analysis under revision after review).
- **Locality (agent `locality`, ~10k GF runs, under review):** for two-component teachers the gap exponent is k - 2 with
  k = Steiner-subtree core count, on 9 tree types for k = 1..8 (+-0.05 for k <= 4); k = 2 log law with head-start slope
  (1 - s2/s1)/lambda2 (1/lambda2 from a saddle start); H3 by lambda_min scaling (-lambda2 for k = 2, sigma^(k-2) for k >= 3);
  same teacher S = {3,4}, N = 8: MPS log, binary sigma^-3, HT sigma^-5.7; rising edges = Steiner edges in 98.7% of 5132
  events; k readable from one run via the growth exponent; for >= 3 components the route rule at rank-constrained optima
  (not literal H2) predicts 7/7 teachers; dead routes only k >= 4 with fan-in init, removed by balanced init or spare chi.
- **Optimization (agent `optim-samples`, under review):** eta_max = 2/(K s_1^(2-2/K)) exact at small init; GD = GF + O(eta)
  shift predicted to 3 digits; above eta_max a 1D-map 2-cycle (loss to 3-4 digits), then divergence / return to the origin;
  SGD never shortens plateaus, lengthens/traps later ones (depends on eta/B only); finite samples: small init recovers W*
  with its bond ranks from n ~ 250, lazy limit never at finite chi; generalization degrades monotonically with init scale.
- Local H2 pilot (experiments/pilot_h2_locality, d = chi = 2): H2 exponents hold wherever the second component is learned
  (k = 3, 4, 5, 7 on MPS4/6, binary4/8); first escape sigma^-(K-2) to +-0.003. COLLAPSE: with chi = 2, 95/332 runs with
  k >= 4 never learn the second component (route ends die to 1e-12..1e-16; failing seeds fixed across sigma); MPS6 k = 5-6
  exponents seed-dependent and steeper than -(k-2). Spare channels (chi > R) expected to cure it (theory_regimes P14).
- Experiments (interim): locality N=4 exponents match k = 1, 2, 3, 4 (incl. head-start log slope 1.005 vs 1.0);
  data-teacher: aligned covariance = race with weights Lambda s, landscape with sqrt(Lambda) s; optim-samples:
  eta_max = 2/(K s_1^(2-2/K)) exact, GD event shift predicted to 3 digits.
- Theory (proven, report Appendix A prop:A-kkt): every KKT point of g = <W, W*> on the unit sphere with g* > 0 is exactly
  balanced on every bond with core norms 1/K, so the near-origin escape direction is balanced and min-norm.
- Lazy regime: the tangent kernel of a random TTN is isotropic only on average; a single draw is strongly
  anisotropic unless every chi_e >> cut dimension min(d^n_e, d^(N-n_e)), so finite-chi lazy runs have an order
  and end at the projected fit.
- Dynamics: non-learned components rise transiently while another is learned (a_2 up to 0.41 on binary N = 4),
  so event widths use the final rise.
- Library: the two-copy model is not a doubled-bond TTN without a gradient mask; centred/two-copy losses
  cancel catastrophically at large sigma (use the cancellation-free forms); teacher/init RNG streams were shared
  (fixed in 57d5262).
